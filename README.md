# Simple To-Do List

A simple Python-based to-do list application created as a class project.

## Features

* Add tasks
* Display tasks
* Validate empty task input

## Purpose

This project demonstrates a basic GitHub team workflow, including:

* Git repository management
* Issues and task assignment
* Feature branches
* Commits
* Pull Requests
* Peer code review
* Resolving review comments
* Merging approved changes

## Team Workflow

The team follows a feature-branch workflow. Each task is assigned to a team member, developed in a separate branch, reviewed through a Pull Request, and merged into the `main` branch after approval.
